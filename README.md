# MeetSync – Secure WebRTC Video Conferencing

MeetSync is a **real-time video conferencing web application** that enables users to communicate through **video, audio, chat, and screen sharing** directly from their browser.
The application uses **WebRTC for peer-to-peer media streaming** and **Socket.io for real-time signaling**.

This project demonstrates building a **full-stack real-time communication system** similar to platforms like Google Meet or Zoom.

## ⚙️ How It Works

1. Users join a meeting room using a unique URL.
2. Socket.io manages the **signaling process** between peers.
3. WebRTC establishes **peer-to-peer media connections**.
4. Media streams (audio/video) are exchanged directly between users.

## 📚 Key Concepts Implemented

* WebRTC Peer Connections
* ICE Candidate Exchange
* Real-time signaling with Socket.io
* Media stream handling in browsers
